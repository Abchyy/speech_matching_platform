# speech_matching_platform

面向中小型 AI 科技企业的总书记重要讲话智能匹配与政企沟通材料平台。

## 项目目标

帮助企业将自身技术、产品与产业方向，匹配到总书记重要讲话和重要论述，沉淀可复用、可追溯、可人工控制的政企沟通话语资产，并生成适配具体沟通场景的文字材料。

## 当前阶段

**M0：Repository Bootstrap（项目初始化）**

当前仅完成仓库结构、设计文档整理与协作基线准备，尚未进入业务开发。
